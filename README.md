# IEM Events — CSE (AIML)

A responsive event management website for the Department of CSE (AIML), Institute of Engineering & Management, Kolkata.

## Features
- Upcoming events and search
- Category filtering
- Bookmark events using localStorage
- Event countdown and digital clock
- Dark/Light mode
- Registration and feedback forms
- Gallery with lightbox
- Responsive design

## Technologies
HTML, CSS, JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html` in a browser or use Live Server.
